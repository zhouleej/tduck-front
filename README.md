# 云卷问卷平台

云卷问卷平台是面向企业与政务场景的问卷设计、数据采集与短信邀请系统，支持拖拽式问卷、权限管理、联系人名单、匿名或跟踪邀请、回执同步和统计导出。

## 本地运行

- 前端：`npm install` 后执行 `npm run dev`，默认端口 8888。
- 后端：`mvn -pl tduck-api -am package -DskipTests`，再启动 `tduck-api/target/tduck-api.jar`，默认端口 8999。
- 前端开发代理指向 `http://127.0.0.1:8999`。

## 问卷短信能力

真实短信能力默认关闭。启用前请配置公网 HTTPS 邀请地址、已审核模板和云信开放接口参数，并先完成小规模授权号码验收。名单导入上限为 1 万条，批次创建前必须完成预览确认。

详细迁移、部署、回滚和验收步骤见后端 `doc/问卷短信调研部署与验收.md`。
