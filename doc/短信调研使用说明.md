# 短信调研

前后端配套分支：`codex/survey-sms-workflow`。

问卷编辑页新增“短信调研”，包含对象名单、模板、邀请批次及回复；问卷统计页新增邀请回收统计。管理员系统配置页提供调研开关、云信能力开关和已验证查询配置；管理端收件箱提供人工分配、拒收管理及同步状态。

使用顺序：导入并预检名单→设置匿名或跟踪模式→绑定已审核模板及变量→预览对象与内容→创建立即或预约批次→查看提交和送达状态→填写与回收→人工催答或再次邀请→导出。首批创建后模式锁定，匿名模式不显示逐人答卷。

默认关闭真实发送。邀请地址必须配置公网 HTTPS 域名，并让 `/i/标识` 支持前端路由回退；localhost 链接不能用于外部受邀者。前端 `npm run build` 通过后部署 `dist`，同时升级后端并执行六个增量脚本。

详细配置、迁移顺序、状态处理、验证结果和回滚步骤见后端仓库 `doc/问卷短信调研部署与验收.md`。本次开发没有发送真实短信，正式上线前还需完成少量授权号码的实际端到端验收。
