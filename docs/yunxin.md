# 移动云云信配置与问卷短信邀请

配套后端为 `tduck-survey-form`，接口协议和原始 PDF 差异说明见后端仓库 `doc/云信平台API接口说明V1.5.4.md`。前后端需同时更新；本功能复用现有 Vue 2、Element UI、请求签名与系统环境配置接口。

## 1. 管理员配置

进入“系统配置 → 短信配置”，服务商选择“移动云云信”，填写：

| 配置 | 说明 |
| --- | --- |
| 云信网关地址 | 开户方提供的根地址，例如 `https://gateway.example.com`，可带端口，不包含接口路径 |
| 云信用户名 | 平台用户名，与企业 ID 不同 |
| 企业 ID | CRM 分配的 12 位数字，按字符串保存 |
| 接入号 | CRM 分配的 8 位数字 |
| 扩展码 | CRM 分配的 6 位数字，保留前导零 |
| 发送接口路径 | 默认文档定义的 `/prod-api/tripartite/task/v2/send`；仅在实际网关要求时选择原版 `/prod-api/tripartite/task/send` |
| 问卷邀请默认模板 ID | 已审核通过的邀请模板，发布页可以指定其他模板 |
| 短信验证码模板 ID | 用于原有手机号验证；仅发问卷邀请可不填；模板中 `#params_1#` 接收验证码 |

点击“保存配置”后由后端现有配置刷新事件更新短信发送器。其他短信服务商仍沿用原有配置方式。

## 2. 准备审核模板

云信变量值最多 20 个字符，推荐将实际问卷域名和 `/s/` 写在固定内容中，将问卷编号作为变量：

```text
【您的签名】诚邀您参与调查，请访问：https://survey.example.com/s/#params_1#
```

请替换真实签名和实际公网域名，在云信平台创建变量文本模板并通过审核。对问卷编号 `AbCd1234`，发布页默认传入 `p1=AbCd1234`，受访者收到的链接为 `https://survey.example.com/s/AbCd1234`。域名必须与当前问卷的真实填写地址一致。

也可使用普通文本模板，将当前问卷的完整地址直接写进审核模板；这种模板不会在发送时自动插入或替换链接。

## 3. 发布页发送

1. 打开问卷并完成发布，在发布页找到“短信邀请”。
2. 确认邀请模板 ID，输入 11 位手机号，使用换行、空格、中英文逗号或分号分隔，每次最多输入 100 个号码。重复号码自动去重，无效号码会阻止整次提交。
3. 选择与实际审核模板一致的类型。变量模板默认填入问卷编号到 p1，也可按审核内容添加 p2 至 p30；单个变量为 1 至 20 个字符。普通模板不提交变量。
4. 点击“发送短信邀请”，确认人数和模板链接后提交。系统展示云信受理的号码数、任务 ID 和批次号。

“已受理”表示网关接受发送任务，实际送达请在云信平台查询。超时或断连时不要直接重复发送，应先核实任务是否已受理。模板创建、审核查询、回执和历史任务查询目前仍在云信平台操作。

配置未启用时显示联系管理员的提示；配置加载失败可重试。邀请接口需要登录和问卷权限，后端会拒绝未发布、已删除或文件夹表单。

## 4. 验证与构建

```powershell
npm ci
npx eslint src/views/manage/system/index.vue src/views/form/publish/SmsInvite.vue src/views/form/publish/index.vue src/api/project/sms.js
npx eslint --no-ignore vue.config.js
$env:NODE_OPTIONS='--openssl-legacy-provider'
npm run build
```

当前 Vue CLI 4 / Webpack 4 在本机 Node 22 下验证时使用上述 OpenSSL 兼容参数。构建配置优先使用存在的本地表单编辑器源码，否则使用项目已安装的 `tduck-form-generator`，避免缺少相邻源码目录时无法构建。

本次已完成前端生产构建、修改文件 ESLint 检查，并在本地模拟接口上检查配置保存、前导零保留、手机号必填/去重和邀请请求参数。后端通过 16 项模拟网关、权限和参数校验测试。真实云信变量模板发送联调已查询到发送状态“成功”，手机送达需以运营商送达回执为准。
